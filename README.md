# Netflix Data Analysis Project

## Project Overview
This project explores the Netflix Movies and TV Shows dataset using Python and data analysis libraries.

The aim is to understand Netflix's content library, identify patterns, clean the dataset, and present useful insights through visualizations.

## Dataset
**Dataset:** Netflix Movies and TV Shows

**File:** `netflix_titles.csv`

The dataset contains information about Netflix movies and TV shows, including:

- Show ID
- Type (Movie or TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

## Tools and Technologies
The following tools and libraries are used:

- Python – Programming language
- Jupyter Notebook – Data analysis environment
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization

## Project Objectives
1. Load and explore the Netflix dataset.
2. Identify missing values.
3. Clean and format columns.
4. Check for duplicate records.

## Project Workflow

### 1. Data Loading
Import the dataset into Jupyter Notebook using Pandas.

### 2. Data Exploration
Examine the dataset using:
- `head()`
- `tail()`
- `columns`

### 3. Data Cleaning
The cleaning process includes:
- Checking for missing values.
- Handling empty cells.
- Removing duplicate records.
- Removing unnecessary spaces.
